# MOOD Studio

브라우저에서 작동하는 한국어 쇼핑몰 이미지 편집 스튜디오입니다.

- 썸네일: 이미지 업로드, 기기 내 AI 피사체 분리, 단색 및 도형 기반 배경 합성, 비율 선택, PNG 저장.
- 후보정: 밝기·대비·채도·따뜻함, 원본 비교.
- 상세페이지: 자체 제작 미니멀·러블리·스트릿 템플릿, 문구 수정, 900×2450 PNG 저장.
- 마진: 할인 후 상품 판매가 기준 수수료, 원가·배송비·포장비 반영. 세금·반품비 제외.

`dist`를 정적 서버로 제공하세요. 배경 제거는 `@imgly/background-removal@1.7.0`을 esm.sh에서 로드하며, 첫 실행 시 모델 다운로드가 필요합니다. 사진은 브라우저에서 처리합니다. 생성형 배경이 아니라 피사체 분리 후 준비된 배경에 합성하는 방식입니다. 네트워크 및 메모리 제약에 따라 배경 제거가 실패할 수 있습니다.

샘플 이미지로 사용자가 제공한 사진을 사용했습니다. 폰트는 Google Fonts에서 불러오며, 실패 시 시스템 폰트로 표시됩니다.

배경 제거 라이브러리의 AGPL 라이선스와 상용 라이선스 선택 사항은 상용 서비스 운영 전 확인이 필요합니다. 초기 버전은 원격 계정·서버 저장 없이 현재 브라우저 세션에서 편집합니다.
